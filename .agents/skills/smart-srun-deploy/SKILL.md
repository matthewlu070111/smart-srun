# smart-srun 开发部署

读取[部署手册](../../../doc/development/deployment.md)，先确定当前授权的目标设备、
安装布局和实际版本。只核验与本次任务相关的状态，不把旧设备记录当作当前事实。

使用现有 `scripts/hot_update.py` 包部署入口及精确原版本恢复包。
根据任务范围选择本地 `--dry-run`、设备只读 `--probe`、上传核验 `--prepare` 或实际更新；
后三者的副作用不同，手册有明确边界。首次安装使用原生包管理器。

不混用 bundle/split，不用 Python 旧运行时覆盖 Go，不绕过原生可信验签。
失败时读取独立 Worker 状态与实际包版本，再依手册恢复；不要因客户端等待结束就重试安装。
未知凭据的受保护设备保持只读。确认运行文件、网络和配置后，再按本次任务要求开始新验证。
汇报实际完成阶段与未执行项，不把提交更新任务当作更新成功或长测通过。
