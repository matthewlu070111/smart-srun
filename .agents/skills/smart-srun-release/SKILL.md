# smart-srun 候选发布

读取[构建与发布手册](../../../doc/development/build-release.md)中本次操作对应的章节，
以及[工作流约束](../../../.github/AGENTS.md)。命令参数以实际脚本 `--help` 为准。

先明确版本、源码状态、目标 SDK、签名身份和本次任务的授权范围。
使用现有构建、验包与清单工具，让验证报告绑定实际包 SHA256。
复用已验证产物创建草稿；不要覆盖旧版本或用临时预览密钥替代正式身份。

缺少正式密钥、原生可信验签或必要证据时，报告具体缺项；不能降级成跳过验证。
输出中区分构建、版本启动、安装、真机与校园验收；未执行的项目保留为未完成。
创建草稿不代表获得公开发布授权，旧任务的授权也不延续到当前任务。
