# 默认 SRun 配置

默认运行时适用于采用常见深澜 SRun 网页认证流程的校园网。学校预设用于预填参数；各学校的网关、AC_ID、接入方式和运营商后缀以 [学校预设清单](school-presets.json) 及实际认证页面为准。

## 配置步骤

1. 选择学校预设并应用，核对认证网关 `base_url` 与 `ac_id`。没有对应预设时，可以使用默认运行时并手动填写参数。
2. 按实际接入方式配置校园 Wi-Fi 或有线接口；同一学校的有线、无线和不同校区参数可能不同。
3. 账号框填写账号主体，运营商后缀单独填写，不要在两处重复加入后缀。后缀留空时使用纯账号，非空时按 `账号@后缀` 登录。
4. 只有确认网页登录请求与默认值不同时，才调整账号高级登录参数，如 `n`、`type`、`enc`、`info_prefix`、`double_stack`、`login_os` 和 `login_name`。账号参数优先于旧全局配置。

不确定参数时，使用 [网页采集脚本](srun-portal-diagnostic.md) 获取实际请求，避免根据学校名称或运营商名称猜测。

## 运营商后缀

- 后缀取自真实登录账号或请求。门户选项中的产品序号不一定属于账号后缀。
- 南昌航空大学前湖校区的学生用户使用 `stu.nchu.edu.cn`，不能把旧采集结果 `1-@stu.nchu.edu.cn` 直接填入后缀框。有线拨号及其他套餐需单独核对。
- 网络接入商是中国电信，不代表认证后缀一定是 `ctcc`；其他运营商同理。预设里的 `??` 表示后缀尚未确认，需要核对后再使用。

## 连接检查

先确认路由器已接入校园网且认证网关可达。网关可达但外网探测失败，只能说明当前连通性尚未确认；应结合认证结果和网页登录情况排查。使用网关探测模式时，探测成功也不等于外网已经可用。

同一账号由多个认证客户端同时维护时，可能互相抢占会话。排查前检查是否存在其他正在运行的认证客户端。
