## 4. JSON 格式与防回归

- 主清单、fallback、运行时缓存共用 `school_presets.format_preset_payload()`。
- 统一语义键序、2 空格缩进、对象/数组展开、UTF-8、LF 和一个末尾换行。
- 主清单与 fallback 除顶层 `source` 外内容相同。
- 格式函数保留未知扩展字段、原学校顺序、缺失值和状态，不把缺失信息替换成猜测值。
- `.gitattributes` 固定两份预设的 LF，避免 Windows checkout 引入无意义差异。

维护命令：

```sh
python scripts/format_school_presets.py --write
python scripts/format_school_presets.py --check
```

默认不带参数执行只读检查。pytest 校验两份数据同步、格式、ID 唯一性、suffix 字段、原始 Issue 参数和草稿可见性。

草稿可见性同时覆盖 Python 列表、刷新接口结果和 Node 执行的实际前端函数。回归还验证：远端将学校改为非 active 后，不会被随包 active 状态覆盖；远端暂缺的随包学校仍保留；用户自定义预设仍可查找；刷新为空时清除旧公共列表。
